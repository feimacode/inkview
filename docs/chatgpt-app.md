# Inkview as a ChatGPT app

ChatGPT connects to remote MCP servers only, so this uses the hosted server
(or your own deployment, see [self-hosting](self-hosting.md)). Local `npx` does not work here.

## Create the app in developer mode

1. In ChatGPT, open **Settings → Apps & Connectors → Advanced settings** and turn on **Developer mode**.
2. Back in **Apps & Connectors**, choose **Create** and fill in the fields below.
3. Tick that you trust the server, then **Create**.
4. In a new chat, pick Inkview from the **+ → Developer mode** menu and try a prompt from the README.

ChatGPT's settings move from time to time; if a menu name differs, look for "Developer mode" and "Create app".

| Field | Value |
| --- | --- |
| Name | Inkview |
| Description | Shows people, tables, search results, companies, comparisons, charts and products as interactive components in the chat. |
| Icon | [`docs/img/icon.png`](img/icon.png) (512 × 512) |
| MCP server URL | `https://<hosted domain>/mcp` |
| Authentication | No authentication |

## Instructions

ChatGPT reads the server's `initialize` instructions automatically. For the app
directory submission, or a custom GPT that uses Inkview, use this text:

<!-- guidance:start (generated by npm run gen:guidance, do not edit) -->

```text
Inkview shows structured answers as interactive components. Gather data with your other tools first, then call the matching Inkview tool:
- One person (candidate, speaker, founder, contact): show_profile_card
- Several people (candidates, speakers, attendees, contacts): show_profiles
- 3 or more records with the same fields: show_table
- Web, news, paper or document search results: show_results
- One company, organization, product or place: show_entity_card
- 2 to 5 options the user is choosing between: show_comparison
- Numbers over time or across categories: show_chart
- Shopping results (2 to 12 products): show_products
- Structured data that fits none of the above clearly: show_auto
Pass only data you gathered from your tools or the conversation. Never invent fields such as image URLs, links, prices or ratings.
After rendering, add at most one sentence. Do not repeat what the component shows.
Prefer the specific tool over show_auto when the situation is clear.
Answer in plain text when the answer is a single fact, a short explanation, or code.
```
